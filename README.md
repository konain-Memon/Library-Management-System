 # Library Management System - Java OOP Project

**Subject:** Object Oriented Programming (OOP)

## Project Description
This project is made for a Library.
In this project, we can add Books, register Members,
Issue / Return Books and manage the complete record of the Library.

## Files - 6 Files

### 1. Book.java
It stores the details of a Book - like Book Name, Author, ID and whether it is available or not.

### 2. Member.java
It stores the details of a Library Member - like Member Name, ID and which book the member has taken.

### 3. Library.java
It performs the main work of the Library - adding a Book, searching a Book and showing the list.

### 4. Transaction.java
It keeps the record of Book Issue and Return - who took which book and when it was returned.

### 5. Librarian.java
It manages the work of the Librarian - managing Books and Members.
